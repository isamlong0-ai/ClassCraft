Profil Sekolah Data Guru Kelola Kelas Backup & Restore

Backup Database & File

Mengunduh seluruh data sistem ke file JSON, termasuk database dan file KOP/TTD (bucket sekolah-assets).

Backup terakhir lebih dari 7 hari yang lalu. Segera unduh backup baru.
Backup terjadwal (opsi bawaan Supabase)
  1. Dashboard Supabase → Project → Database → Backups → aktifkan Scheduled Backups (memerlukan paket Micro/Team ke atas).
  2. Jika paket gratis: gunakan cron eksternal (mis. GitHub Actions / layanan cron.com) yang memicu job pg_dump ke storage bucket atau mengirim file hasil dump via email, lalu unduh ke komputer Anda.
  3. Alternatif lokal paling aman: unduh backup dengan tombol di atas secara berkala (mis. setiap minggu sebelum awal semester atau setelah perubahan besar).

Restore dari Backup

Mengembalikan seluruh data dari file backup (.json). Data yang ada akan tertimpa. Butuh password admin.

Cara restore lengkap di proyek baru
  1. Buat user Auth di Dashboard Supabase → Authentication → Add User, untuk setiap username pada file backup (authUsers). Email = username@classcraft.local. Atur password sementara.
  2. Isi tabel guru: insert baris dari backup (ID harus sama dengan Auth user yang dibuat).
  3. Kelola restore ini: masuk sebagai admin, pilih file backup, lalu klik Restore. File restore akan membuat sisa data.
  4. Password tidak bisa dipulihkan; setiap user harus reset password (Dashboard atau fitur Reset Password).

Kosongkan Semua Data (Zona Berbahaya)

Menghapus seluruh data sistem (siswa, presensi, jurnal, bank soal, modul ajar, dsb). Data yang terhapus tidak bisa dikembalikan. User admin TIDAK dihapus.
